01 / ゴール・KGIを定める↗

目指す成果が揃っていない

達成したい状態と、成果を確かめる数字を合意する。

 02 / CSF・KPIを選ぶ↗

どこを改善すべきか絞れない

成果を妨げる場所を見つけ、いまの重点を1つに。

 03 / 測り方・判断条件を決める↗

測り方や判断の基準が決まらない

測り方を揃え、目標値・停止条件・判断日を決める。

 04 / 行動を決め、実行する↗

数字を見ても、次の行動が決まらない

今週の一手、担当、期限、必要な支援を決める。

 05 / 成果を確かめ、見直す↗

改善が成果につながったか分からない

成果へのつながりを確かめ、施策やCSF・KPIを見直す。

選ぶために広く知る。追うときは絞る。

チームの重点KPIは1つ。重点KPIの改善が負担を移す先（品質・人の負荷・費用・測り方・顧客）の悪化に気づくカウンターメトリクス（ガードレール指標）は2〜4個で、閾値を置きます。その他は四半期の全体確認と、必要時の見直しに使う参照値。KGI（成果について期限までに達成する目標数値）は、これらとは別に保持します。第1章でKGIの決め方を読む → 複数チームの持ち方は第2章 → 成果の責任と実行の責任の分け方は第1章 →

これは本資料の運用方針です。移り先の整理も本資料のもので、5つで尽きるとは限りません（なぜ、その指標が対になるのか）。
