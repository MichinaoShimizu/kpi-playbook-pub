品質・信頼性・安全性

復旧目標と復旧訓練の達成率

RTOは障害から復旧までの目標時間で、事業の最大許容停止時間以内に設定します。RPOは許容するデータ損失の時間幅。訓練で両方を検証。

RTO / RPO / Restore Test

使い方の例：工程を改善する / KPI候補KGI・KPIの選び分け用語（KGI・CSF・KPI）

この指標に対応するプロセスが、いまのCSFである場合にKPI候補となります。KGIへのつながり、改善できる範囲、測定条件と目標値を合意してから採用します。

定義と測り方

復旧訓練の達成率 = RTO・RPO双方を満たした訓練数 ÷ 実施訓練数

システムごとのRTO・RPO（事業側と合意した値）、訓練の実施記録（日付・シナリオ・かかった時間・失われたデータの幅）、未訓練のシステム一覧を取ります。目標と実績は別欄にし、達成の判定（両方を満たしたか）を訓練ごとに残します。実際の障害での復旧時間は、訓練と区別できる印を付けて実績の欄に並べ、達成率の分母には入れません。訓練とバックアップの持ち主（インフラ・情報システム担当など）と、開発チームが自分で直せる範囲（手順・アプリの依存先）を先に分けます。

率を使う指標は対象件数を併記し、分母ゼロは未定義、欠損は不明として扱います。期間・対象・除外条件・担当は運用シートに残します。

この項目を使うとき

バックアップと復旧手順が、事業が許容する停止時間（RTO）とデータ損失（RPO）の中で本当に戻せるかを確かめるとき。訓練の実施と達成を進める改善のKPI候補です。

採用する前に

達成率を目標に置くと、戻しやすいシステムだけを訓練する、シナリオを簡単にする、で上がります。バックアップの取得成功を復旧可能と読みません。RTO・RPOを実績に合わせて緩めて達成させません。未訓練のシステム数を併記しないまま率だけを報告しません。

KPIの基準値と目標を合意する

KPIに置くなら、対象を先に固定し（例：重要度Aのシステム）、その範囲の達成率で目標を置きます。未訓練のシステム数とシナリオの範囲は目標ではなく、閾値として別に見張ります。訓練の実施時間帯（業務時間内か休日か）と担当の偏りを併記し、稼働の健全性の閾値の中で計画します。

カウンターメトリクス（ガードレール指標）

対にする指標の考え方と、閾値の決め方・超えたときに止めるもの

対に置くのは、この指標の数字を良くしようとする行動が、品質・負荷・費用に出す副作用を捉える指標です。数字は、仕事の中身を良くしなくても、負担を別の場所へ移すことで動きます。移した先はこの指標には表れません。下の候補は、その移り先（品質、人の負荷、費用、測り方、顧客）を先に決めて見張るためのものです。この移り先の整理は本資料の運用案で、調査で得た知見ではありません。どこへ移るかはチームが実際に採る行動で変わるため、写す前に自チームの行動から選び直してください（なぜ、その指標が対になるのか）。

対に置く指標は達成目標ではなく、超えたら止める閾値として使います。何から決まる閾値かを先に決めてください。法令・労使協定・社内規程で上限が決まっている項目と、顧客が必要とする水準や予算・資金の制約から決まる項目は、自社の分布からではなく、その上限・要求・制約を根拠にし、上限に達する前に手を打てる水準に置きます（上限そのものを閾値にしません）。自社の分布から決める項目は、基準値とばらつきから置きます（閾値の決め方と停止・再開条件）。

超えたときに止める対象、再開を判断する人、再判定の時期をチームで決め、運用シートに残します。止めるのは閾値に触れさせた施策や進め方で、保守・セキュリティ更新のような投資の区分を止めることではありません。

  • 未訓練システム数
  • 訓練シナリオの範囲
  • 平均復旧時間
  • 稼働の健全性

上の候補からチームで2〜4個を選び、達成目標ではなく超えたら止める閾値として置きます（個数は本資料の運用方針）。対に置くのは、この指標の数字を良くしようとする行動が品質・人の負荷・費用・顧客へ出す副作用と、数え方の変更を捉える指標です。法令・労使協定・社内規程の上限、顧客の要求、予算の制約から決まる項目は、先にそれを確かめます。選ばなかった項目は四半期の確認に回し、観点だけが並ぶ場合は自チームで閾値を置ける指標に具体化してから使います。止めるのは閾値に触れさせた施策や進め方で、止める対象・再開を判断する人・再判定の時期を運用シートに残します。

目標と実績を別欄に記録。未訓練システム数も併記し、バックアップ取得成功だけで復旧可能としない。

打ち手と確かめ方

未達のシステムは、手順・権限・バックアップの世代・依存先の順で原因を切り分けて直し、再訓練します。未訓練のシステムを重要度順に訓練の計画へ入れます。訓練で満たせても、実際の障害で戻せなかった件は別に振り返ります。

率が上がった期に、訓練の対象範囲とシナリオが狭まっていないか、RTO・RPOが緩められていないかを確認します。実際の障害での復旧時間が訓練の結果と大きく違う場合は、訓練の条件を見直します。
